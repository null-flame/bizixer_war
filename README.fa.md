## مقدمه

**Bizixer War** یک بازی استراتژیک چندنفره جنگی است که با فریمورک FastAPI توسعه یافته است. بازیکنان می‌توانند به یکی از سه تیم (مهدی، فری، گوجی) بپیوندند و برای ساخت کارخانه‌ها، تولید موشک‌ها و حمله به پایگاه‌های دشمن رقابت کنند. این بازی دارای یک سیستم اقتصادی مبتنی بر منابع است که بازیکنان باید به صورت استراتژیک منابع سکه‌ای خود را مدیریت کنند تا توان نظامی خود را گسترش دهند.

## ویژگی‌ها

### ویژگی‌های اصلی
- **سیستم چند تیمی**: ۳ تیم مجزا (مهدی، فری، گوجی)
- **احراز هویت ایمن**: سیستم احراز هویت مبتنی بر JWT با ذخیره‌سازی کوکی
- **مدیریت منابع**: سیستم اقتصادی مبتنی بر سکه با تولید خودکار
- **سیستم کارخانه**: ۴ سطح کارخانه (T1-T4) با نرخ تولید متفاوت
- **سیستم موشک**: ۴ سطح موشک (T1-T4) با آسیب و زمان ساخت متفاوت
- **سیستم رزم**: حمله به بازیکنان دشمن با حملات موشکی استراتژیک
- **سیستم صف**: تولید ناهمزمان موشک‌ها با تایمر شمارش معکوس
- **تابلوی امتیازات**: رتبه‌بندی بلندمدت تمام بازیکنان

### موجودیت‌های بازی

| نوع | T1 | T2 | T3 | T4 |
|-----|----|----|----|----|
| **هزینه کارخانه** | ۳۰ | ۵۰۰ | ۱۰٬۰۰۰ | ۱۰۰٬۰۰۰ |
| **تولید کارخانه (به ازای هر ساعت)** | ۱۲ | ۱۲۵ | ۶۲۵ | ۲٬۰۸۳ |
| **سلامت کارخانه** | ۹۰ | ۱٬۵۰۰ | ۱۵٬۰۰۰ | ۱۵۰٬۰۰۰ |
| **هزینه موشک** | ۴۸ | ۶۰۰ | ۲٬۵۰۰ | ۱۰٬۴۱۵ |
| **زمان ساخت موشک (دقیقه)** | ۵ | ۳۰ | ۱۲۰ | ۲۴۰ |

## فناوری‌های مورد استفاده

- **Backend**: [FastAPI](https://fastapi.tiangolo.com/) - فریمورک مدرن و سریع وب برای پایتون
- **دیتابیس**: [SQLModel](https://sqlmodel.tiangolo.com/) + [SQLAlchemy](https://www.sqlalchemy.org/) با [aiosqlite](https://github.com/jreese/aiosqlite) برای SQLite ناهمزمان
- **احراز هویت**: JWT (JSON Web Tokens) با [python-jose](https://github.com/mpdavis/python-jose)
- **اعتبارسنجی**: [Pydantic](https://pydantic.dev/) برای اعتبارسنجی داده‌ها
- **محيط**: [python-dotenv](https://github.com/theskumar/python-dotenv) برای پیکربندی
- **Type Hints**: پشتیبانی کامل از نوع‌دهی پایتون

## نصب و راه‌اندازی

### پیش‌نیازها

- پایتون ۳.۱۰ یا بالاتر
- pip (مدیر بسته‌های پایتون)

### شروع سریع

1. **کlon کردن مخزن:**
   ```bash
   git clone https://github.com/your-username/bizixer_war.git
   cd bizixer_war
   ```

2. **ایجاد محیط مجازی (پیشنهادی):**
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # در ویندوز: .venv\Scripts\activate
   ```

3. **نصب وابستگی‌ها:**
   ```bash
   pip install -r requirements.txt
   ```

4. **پیکربندی محیط:**
   ```bash
   cp .env.example .env
   # ویرایش .env با کلید مخفی خود
   ```

5. **اجرای برنامه:**
   ```bash
   uvicorn app.main:app --reload --port 8000
   ```

6. **دسترسی به API:**
   - Swagger UI: `http://localhost:8000/docs`
   - ReDoc: `http://localhost:8000/redoc`

### نصب با pip (گزینه جایگزین)

```bash
pip install flit
flit install
```

## پیکربندی

### متغیرهای محیطی

یک فایل `.env` در ریشه پروژه ایجاد کنید:

```env
# کلید مخفی JWT (اجباری)
sec=کلید-مخفی-ایمن-شما-اینجا

# آدرس دیتابیس (اختیاری - به صورت پیش‌فرض SQLite)
DATABASE_URL=sqlite+aiosqlite:///db.db
```

> **مهم**: متغیر `sec` برای امضای توکن‌های JWT استفاده می‌شود. از یک رشته قوی و تصادفی (حداقل ۳۲ کاراکتر) استفاده کنید.

## مستندات API

### نقطه‌های انتهایی احراز هویت

| روش | آدرس | توضیح |
|------|-------|---------|
| POST | `/api/v1/register` | ثبت‌نام کاربر جدید |
| POST | `/api/v1/login` | ورود و دریافت توکن JWT |

### نقطه‌های انتهایی بازی

| روش | آدرس | توضیح |
|------|-------|---------|
| POST | `/api/v1/get_coin` | جمع‌آوری سکه‌های تولید شده |
| POST | `/api/v1/buy_factory` | خرید کارخانه |
| POST | `/api/v1/buy_missile` | خرید موشک (ورود به صف تولید) |
| POST | `/api/v1/attack` | حمله به بازیکن دیگر |
| POST | `/api/v1/get_missiles` | جمع‌آوری موشک‌های ساخته شده از صف |
| GET | `/api/v1/info` | دریافت اطلاعات کاربر فعلی |
| GET | `/api/v1/leaderboard` | دریافت رتبه‌بندی تمام بازیکنان |

### نمونه درخواست‌ها

**ثبت‌نام:**
```bash
curl -X POST "http://localhost:8000/api/v1/register" \
  -H "Content-Type: application/json" \
  -d '{"username": "player1", "password": "secure123", "front": "mahdi"}'
```

**ورود:**
```bash
curl -X POST "http://localhost:8000/api/v1/login" \
  -H "Content-Type: application/json" \
  -d '{"username": "player1", "password": "secure123"}'
```

**خرید کارخانه:**
```bash
curl -X POST "http://localhost:8000/api/v1/buy_factory" \
  -H "Content-Type: application/json" \
  -H "Cookie: token=TOKEN_JWT_شما" \
  -d '{"factory_type": "T1", "count": 1}'
```

**حمله:**
```bash
curl -X POST "http://localhost:8000/api/v1/attack" \
  -H "Content-Type: application/json" \
  -H "Cookie: token=TOKEN_JWT_شما" \
  -d '{"Tid": 2, "missile_type": "T1", "factory_type": "T1", "count": 1}'
```

## مکانیک بازی

### منابع اولیه
- **سکه‌های اولیه**: ۵۰۰
- **کارخانه‌های T1 اولیه**: ۱۰۰
- **موشک‌های اولیه**: ۰

### تولید سکه
سکه‌ها به صورت خودکار بر اساس نرخ تولید کارخانه‌ها تولید می‌شوند. هرچه زمان بیشتری بین جمع‌آوری‌ها صبر کنید، سکه‌های بیشتری جمع می‌کنید. هر نوع کارخانه سکه‌ها را با نرخ متفاوتی در هر ساعت تولید می‌کند.

**فرمول تولید:**
```
کل سکه‌ها = (F1 × 12/3600 + F2 × 125/3600 + F3 × 625/3600 + F4 × 2083/3600) × ثانیه‌های گذشته
```

### خرید کارخانه
- کارخانه‌ها سکه‌ها را به صورت مداوم تولید می‌کنند
- کارخانه‌های سطح بالاتر به صورت نمایی بیشتر تولید می‌کنند
- هر کارخانه برای خرید نیاز به سکه دارد
- هیچ محدودیتی برای تعداد کارخانه‌ها وجود ندارد

### سیستم موشک
- موشک‌ها باید با سکه خریداری شوند
- پس از خرید، موشک‌ها وارد صف تولید می‌شوند
- هر نوع موشک زمان ساخت متفاوتی دارد
- موشک‌ها پس از آماده شدن می‌توانند از صف جمع‌آوری شوند
- انواع مختلف موشک آسیب متفاوتی وارد می‌کنند

**فرمول آسیب موشک:**
```
آسیب = هزینه_موشک × تعداد
کارخانه‌های نابود شده = آسیب / سلامت_کارخانه
```

### قوانین رزم
- نمی‌توان به بازیکنان هم‌تیم حمله کرد
- باید موشک کافی برای حمله داشته باشید
- آسیب بر اساس نوع موشک و تعداد محاسبه می‌شود
- کارخانه‌های نابود شده از تعداد دشمن کم می‌شوند
- حداقل تعداد کارخانه ۰ است (نمیتواند منفی شود)
